Project Overview
This is a project done for our Algorithms course.
That meant we had to manually implement many data structures and algorithms rather than relying on Java’s collections.
The program is an abstraction of the workflow of a small street-food stand:
Loading menu items
Processing customer orders
Searching items
Maintaining sales statistics
Sorting and generating reports
everything is done from first principles for educational reasons



### Project Part: Menu Search Algorithms
- **Algorithms**: Linear Search & Binary Search  
- **Data Structure**: Dynamic Array (from scratch)
- **Testing**: Input sizes 100-10,000 items
- **Analysis**: O(n) vs O(log n) comparison
